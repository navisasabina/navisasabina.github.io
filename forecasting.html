About the project

A predictive analytics project that forecasts retail demand from historical sales. The XGBoost model estimates future demand and surfaces the key factors behind each prediction.

To make the model transparent, SHAP (SHapley Additive exPlanations) interprets feature importance so results are easy to understand and explain.

Project objectives

Build a reliable forecasting model that supports data-driven retail decisions and, beyond accuracy, show how each business variable contributes to the result through explainable ML.
